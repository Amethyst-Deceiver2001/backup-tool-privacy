# Privacy policy
This is a personal, single-user backup tool. It accesses only the Google Drive of the account owner, and only files it creates itself (scope drive.file), to store encrypted backups. It collects no data, shares nothing with third parties, and has no other users.
I'm not sure Google accepts github.com as an authorised domain for publishing. It let you enter it, but I can't confirm it passes the publish check, and it would stop at verification. If it doesn't, use the fallback below.
